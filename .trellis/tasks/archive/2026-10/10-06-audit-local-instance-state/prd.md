# 核查本机 new-api 实例/容器的真实状态

## 事由

我上一条汇报说"本机没有 new-api 容器"，依据只有 `docker ps`（仅列**运行中**容器），证据不完整。
用户质疑"本机你不是搭建了吗，你又删除了吗"，需给出准确结论。

## 核查项

1. `docker ps -a`（含已停止容器）里有没有 new-api 相关容器；
2. 本机镜像里 new-api 相关的 tag/摘要（尤其 v0.0.3 是否还在 = 回滚点是否可用）；
3. 我在本机搭建的是哪种形态：`.local-instance/`（进程，非容器）还是容器；
4. 若有容器被删除，能否确认删除时间/原因（不读 /var/log 等沙箱外路径）。

## 核查结论（2026-10-06）

1. **本机没有任何 new-api 容器** —— `docker ps -a`（含已停止）只有 `litepan`、`halo`、`halodb`；
2. **本机搭建的形态是"进程"，不是容器**：`.local-instance/` 下的演示实例
   （二进制 118MB = 0.0.6 构建、`one-api.db`、`data/`、两张验证截图），
   **当前正在运行**：`:3020` 监听 pid=476111，`/api/status` version=0.0.6 → **没有被删除**；
3. **回滚点仍在**：本机镜像含 `ghcr.io/zhemed/new-api-own:v0.0.3`（= 本机 `latest`/`0.0.3` 同一摘要 `3d04916fe29a`）、
   以及 `v0.0.4`、`v0.0.2` 等（合计约 1.5GB，两周前拉取）；
4. 我无法证明"更早是否曾有过一个后来被移除的容器"：docker 不保留已删除容器的记录，
   且我本轮**从未执行过 `docker rm`**（升级命令只写进了留档文档，未运行）；
5. 我上一条汇报的依据只有 `docker ps`（仅运行中），证据不完整——本条已用 `docker ps -a` + 镜像清单补全。
