# 更新确认弹窗保持打开并显示重启进度

## 真实症状（用户）
「点击更新 → 弹窗 → 等一会消失 → 刷新」：升级成功、自动刷新也生效 ✓，
但确认弹窗在点"更新"后**立刻关闭**，中间的"重启中"进度不可见，几秒后页面突然刷新，体验像"弹窗一闪就没"。

代码依据：`handleConfirmUpdate()` 里 `ok` 后 `setConfirmOpen(false)` 立刻执行，
而 `setPhase('restarting')` 的进度提示渲染在**页面里**（弹窗已关，看不到）。

## 修复要求
1. `ok` 后**不要关弹窗**：弹窗内显示**进度**（"正在重启服务…最长约 90 秒，完成后页面会自动刷新" + spinner），
   主按钮**禁用**并改文案（"重启中…"）。
2. 成功 → watcher 调 `window.location.reload()`，弹窗随页面整体消失。
3. **90 秒超时** → 弹窗内改为"更新可能已完成，请手动刷新页面"，主按钮**恢复可用**（点击=关闭弹窗，**不刷新**）。
4. 失败路径（busy/not_newer/下载/校验/替换失败）→ 弹窗保持打开并显示错误（现状不退化）。
5. 既有约束不变：只对 `ok` 启动轮询、按**版本**一次性守卫、失败绝不刷新。
6. 页面常驻提示与弹窗重复 → 自选保留/删除，并在回报说明。

## 测试（必须）
- `ok` 后：弹窗**仍打开**且处于"重启中"（按钮 disabled）；版本变化时 `reload` **恰一次**；
- 超时：弹窗仍打开、显示"手动刷新"文案、点关闭后弹窗消失且**未** reload；
- 失败 reason：弹窗仍打开、显示对应错误、`postUpdateWatch` 未被调用；
- 组件级断言："打开 → 点更新 →（模拟 ok）→ 弹窗 open 仍为 true"。
