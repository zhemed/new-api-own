# 默认范围只留自然月（上月在前）

## 用户决定
「默认范围去掉 1/7/14/30 天这几个选项；本月和上月上下对换（上月在上）」。

## 要做
1. **偏好设置「默认范围」下拉只保留「上月 / 本月」**，顺序**先上月、后本月**；
   - `constants.ts` 的 `NATURAL_MONTH_PRESETS` 改为 `[Last Month, This Month]`（筛选对话框月按钮随之换序，一致性 ✓）；
   - **筛选对话框里的 1/7/14/30 天快捷按钮保留**。
2. **旧值兜底**：用户现存 `{kind:'days', days:30}` → 打开偏好对话框时**显示为「本月」**（`month-to-date`），
   **不静默改存储**；用户点保存后才落盘；保存前图表仍按旧值（30 天）渲染。
   - 解析层（`getSavedChartPreferences` / `buildDefaultDashboardFilters`）**继续接受 `days`**；
     29→30 迁移测试必须继续通过。
3. 下拉取值编码保持 `days:<n>` / `<kind>` 机制，但**不再生成天数项**。

## 测试（必须）
- 偏好下拉选项 = 恰好 `[上月, 本月]`（顺序断言，且不含任何 `N 天`）；
- 旧值 `{kind:'days', days:30}` 打开对话框 → 显示「本月」；**保存后**落盘为 `month-to-date`；
- 解析层仍接受 `days`（→ 09-19 00:00 → now 不变）；29→30 迁移仍通过；
- 筛选对话框快捷范围仍含 1/7/14/30 天与上月/本月，月按钮**上月在前**。
