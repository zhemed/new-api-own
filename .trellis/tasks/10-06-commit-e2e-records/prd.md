# 提交端到端自更新留痕并收尾

## 内容

1. 提交 `10-06-e2e-self-update` 端到端证据记录（3020 从 0.0.6 面板一键升到 v0.0.7）；
2. **更正 Lead 的错误结论**：本会话我曾说"pid 已换 → `syscall.Exec` 生效"——**错误**。
   `syscall.Exec` 在同一进程内替换程序映像，**pid 与启动时间都不变**；pid 变化只出现在
   `restart_mode=exit`（退出交给外部重启策略）那条路径。正确证据应为：同一 pid/启动时间
   + `/proc/<pid>/exe` 的 inode 已指向新文件 + 版本号变化 + 新启动横幅。

- 执行：`POST /api/status/update/apply` → 200（14.61s，下载 118MB + 校验 + 原子替换）；
- 更新后：`version = v0.0.7`；磁盘 sha256 `8634645e…3073` **与 Release 的 `new-api-linux-amd64` 逐字节一致**；
  inode `13791899` == `/proc/537644/exe` inode；面板变「已是最新」、按钮消失、顶栏药丸显示 v0.0.7。
